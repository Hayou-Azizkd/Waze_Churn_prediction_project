# 🚗 Waze Churn Prediction – Project Proposal (PACE Framework)

This repository contains my **portfolio project** for the **Google Advanced Data Analytics Certificate – Course 1: Foundations of Data Science**.

The goal is to design a **machine learning project proposal** for predicting user churn on the Waze navigation app, using the **PACE Framework (Plan – Analyze – Construct – Execute)**.  
This project demonstrates my ability to structure and communicate data projects clearly and professionally — as I prepare for Data / AI internship opportunities.

---

## 🧭 Project Overview

**Waze**, a global community-based navigation app, seeks to improve user retention by reducing churn — the rate at which users uninstall or stop using the app.

This project focuses on developing a **machine learning model** to predict user churn using behavioral and usage data collected from Waze drivers.

An effective churn prediction system will enable Waze to:
- **Identify at-risk users**
- Understand **why and when churn occurs**
- Take **proactive steps** to retain users through personalized engagement

The plan follows the **PACE framework (Plan, Analyze, Construct, Execute)** to organize milestones, manage deliverables, and align with business goals.

> ⚙️ Note: The dataset is **synthetic** (provided by Google for educational purposes) and does not represent real Waze data.

---

## 🎯 Business Problem

User churn impacts:
- Customer retention and satisfaction  
- User growth and engagement  
- Revenue and business expansion  

By leveraging predictive analytics, Waze can:
- Detect users likely to churn  
- Deploy personalized retention campaigns  
- Strengthen customer loyalty and experience

## 🧩 Methodology — PACE Framework

| Stage | Description |
|:------|:-------------|
| **Plan** | Define problem scope, project goals, and structure. |
| **Analyze** | Explore data, clean it, and identify relationships between churn drivers. |
| **Construct** | Build and tune machine learning models to predict churn. |
| **Execute** | Evaluate results, interpret insights, and communicate recommendations. |
